# 모두의 투표

링크 하나로 공유하는 투표 사이트. 계정도 로그인도 없고, 주소를 아는 사람만 참여한다.

## 무엇을 정할 수 있나

투표를 만들 때 아래를 고른다.

| 설정 | 선택지 |
|---|---|
| 유형 | 자유 문항 · 날짜 선택 · 약속 잡기(when2meet 방식) |
| 이름 | 익명 · 기명(참여 시 이름 입력) |
| 개수 | 하나만 · 여러 개 (약속 잡기는 항상 여러 개) |
| 결과 공개 | 투표한 뒤 · 마감된 뒤 · 생성자만 |
| 재투표 | 마감 전까지 수정 허용 · 한 번만 참여 |
| 이름 공개 | 항목별 전체 공개 · 참여자 명단만 |

마감 시각과 비밀번호는 필수다. 비밀번호는 나중에 투표를 고치거나 지울 때 쓴다.

## 스택

React 19 (Vite) · Cloudflare Workers · Workers KV.
Worker 하나가 SPA와 `/api/*`를 함께 서빙한다. `@cloudflare/vite-plugin` 덕분에 `vite dev`가
실제 workerd 런타임을 인프로세스로 띄우므로 개발 중에도 프록시나 CORS 설정이 없다.

```
browser ──▶ Worker
             ├── /api/*  → 라우터 → KV
             ├── /p/*    → 투표별 공유 메타 → 정적 에셋
             └── 그 외    → 정적 에셋 (SPA fallback)
```

## 설계에서 중요한 부분

**표 1장 = KV 키 1개.**
KV는 트랜잭션이 없고 last-write-wins다. 집계 카운터를 키 하나에 모으면 동시 투표가 소리 없이
사라진다. `ballot:{pollId}:{voterKey}` 로 키를 나누면 쓰기 충돌 자체가 생기지 않는다.

**집계는 `list()` 메타데이터만 읽는다.**
표를 쓸 때 집계용 압축 레코드를 KV 메타데이터에 같이 넣는다. 결과 계산은 `list()` 한 번이면
끝나고, 투표자 수와 무관하게 KV 연산이 1회다. 메타데이터 한도(1024B)를 넘으면 그 표만
`get()`으로 떨어진다.

**약속 슬롯은 30분 절대 격자.**
저장 해상도는 언제나 30분이고, 하루를 48비트(base64 8글자) 비트마스크로 담는다. 생성자가
고르는 칸 크기(30/60분)는 표시·집계에만 쓴다. (날짜, 분) 절대 좌표라서 나중에 기간·시간창·칸
크기를 바꿔도 이미 들어온 표를 건드릴 필요가 없다. 범위를 줄였다 다시 넓히면 선택이 그대로
되살아난다.

**비밀번호는 pepper HMAC.**
PBKDF2를 쓰지 않는다. workerd가 반복 횟수를 10만으로 하드캡하는데 이는 OWASP 권장(60만)
미달이고, 무료 플랜 CPU 예산(요청당 10ms)도 거의 다 먹는다. 대신 Worker 시크릿(`APP_SECRET`)을
pepper로 쓴 `HMAC-SHA256(salt || password)`을 저장한다. 시크릿이 KV에 없으므로 KV 덤프만으로는
오프라인 대입이 성립하지 않는다.

## 로컬 실행

```bash
npm install
echo "APP_SECRET=\"$(openssl rand -base64 48)\"" > .dev.vars
npm run dev
```

## 배포

```bash
npx wrangler login
npx wrangler kv namespace create VOTES     # 출력된 id를 wrangler.jsonc에 넣는다
npm run deploy
npx wrangler secret put APP_SECRET
npm run deploy
```

## 알려진 제약

Cloudflare 무료 플랜 KV 일일 한도가 실질 상한이다 (UTC 00:00 리셋).

| | 무료 |
|---|---|
| 읽기 | 100,000 / 일 |
| 쓰기 | 1,000 / 일 |
| list | 1,000 / 일 |
| 저장 | 1 GB |

곧 **하루 총 1,000표**, **결과 집계 1,000회**다. 아이솔레이트 메모(10초)가 새로고침 연타를
흡수하지만 널리 퍼지면 닿는다. 넘치면 Workers Paid($5/월)로 바꾸면 되고, 코드는 그대로다.

- `caches` API는 `*.workers.dev`에서 무동작이다. 커스텀 도메인을 붙이면 활성화된다.
- 결과는 해외 접속자 기준 최대 60초 지연될 수 있다. 본인 표는 항상 즉시 반영된다.
- 링크가 곧 접근 권한이다 (투표 ID 59비트).
- 익명 투표의 중복 방지는 브라우저 저장소 기반이라 시크릿창·기기 변경으로 우회된다.
  계정 없는 투표의 본질적 한계다.
